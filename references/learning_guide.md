## 一、智慧树 / 知到 APP 在线课（官方手册）

### 登录方式

| 身份 | 方式 |
|------|------|
| 新生（首次） | 打开「知到」APP，选**学号登录**：输入学校、学号、初始密码 `Zhihuishu@学号后6位`（首字母 Z 大写；学号不足6位填全部），验证姓氏、绑定手机号后弹出课程确认界面点确认 |
| 老生 | 「学号+学校+原密码」或「手机号+原密码」；忘记密码用原绑定手机号重设；换手机号在【个人资料】改 |
| 电脑端 | www.zhihuishu.com，建议 Chrome / 火狐 |

> ⚠️ 坑：①首次登录**必须用学号登录**（别先注册手机号，否则会提示手机号被占用）；②学习只认角标为「**共享课/智慧课程**」的课，自己加的「兴趣课/公开课」看完**不计分**。

### 成绩组成（先看这个再学）

- 总成绩 = **平时成绩 + 平时测试 + 见面课 + 期末考试成绩**（各部分比例以学校规定为准）
- 平时分 = **学习进度 + 学习习惯 + 问答互动** 三部分

### 平时分攻略（拿满分的核心）

1. **学习进度**：学习时间截止前，看完所有教程视频 + **完成章测试**（章测试也算进度分！别只刷视频）
2. **学习习惯**：**单日视频学习 ≥ 25 分钟**记 1 天规律学习（建议 25-30 分钟）；只算教程视频时长，**不算**见面课和章测试；进度和规律天数**次日上午更新**
3. **问答互动**：有效提问/回答/获有效回答都加分；⚠️ **无效互动**会被清零：灌水帖、抄袭帖、回答少于3字、学习时间结束后发布、回复历史学期提问（25年秋冬学期建议只回复 2025-08-15 之后的）、被 AI/老师删除的
4. ⚠️ **禁言红线**："非人为"刷帖一经发现本学期禁言，且**本学期所有课程**都无法互动问答

### 考试与作业（最容易翻车的地方）

- **章测试**：学习时间截止后无法再提交，注意截止日期；每章有 **3 次重做机会**，取最后一次分数
- **期末考试**：只有 **1 次机会**，一旦打开试卷就开始倒计时，关页面也继续计时，到时自动提交！**别抱着"看一看"的心态点开考试**
- **见面课**：直播或回放都要看；课后测试**只有一次机会**且无"查看答案"功能；回放由多个视频组成时需全部看完
- 视频进度按累计观看时间算，**拖拽播放条不算**；卡顿可调低清晰度；离线学习记录联网后才提交

### 求助渠道

在线客服（Web/APP）、帮助中心、微信小程序「智慧树·教学帮」自助查询

## 二、班委职务与职责（9 大职务）

| 职务 | 核心职责 |
|------|----------|
| 班长 | 总体负责班级工作，安排协调班委；联系学院/老师/同学的桥梁；掌握同学思想动态，向辅导员汇报 |
| 团支书 | 组织团口工作、团员管理；组织**推荐优秀团员为入党积极分子**；配合系里组织志愿服务和社会实践；组织年度评优 |
| 学习委员 | 日常学习事务：考试/教务报名通知、重修补考通知、成绩查询；与任课老师沟通反馈 |
| 生活委员 | 班费管理（每学期公布收支）；督促宿舍卫生；配合生活部大扫除和卫生检查 |
| 组织委员 | 组织团员活动、收团费、会议记录、制订活动计划 |
| 宣传委员 | 班级宣传、宣传资料收集整理上报 |
| 心理委员 | 联系宿舍长发现同学心理问题，配合心理咨询中心做心理普查 |
| 体育委员 | 组织体育活动、带队参加校系体育比赛、管理体育器材 |
| 文艺委员 | 组织文艺活动、配合学院活动、掌握同学文艺才能 |
| 保卫委员 | **督促每日易班签到**；宿舍灯/风扇/空调报修；配合收集返校材料 |

## 三、学生干部竞选（储备干部，官方方案）

- **对象**：2025 级在院/系两委会担任干事或任班委的同学；对学生会有想法的同学
- **流程**：交报名申请表（贴一寸照）→ 系竞选工作小组审核 → **公开演讲**（学工组老师+主席团+部长+班长团支书投票）→ 各部门定 2-3 名储备干部
- **演讲要点**：专业班级姓名政治面貌竞聘岗位 → 干部经历 → 荣誉 → 工作思路，**控制在 4 分钟内**
- **硬条件**：上一学期院系违纪扣分累计 ≤ 10 分；成绩无旷课；禁止拉票（举报核实一票否决）

## 四、新生助导（班助）选拔（信工系）

- **是什么**：协助辅导员带新生的学长学姐，新生入学第一个接触的"老带新"角色
- **选拔流程**：填写《信息工程系新生助导申请表》（贴电子照片）→ 辅导员/系学工组审核签字
- **申请表要点**：成绩排名、有无挂科、所在部门、担任职务、对助导的工作设想、工作经历、所获荣誉
- 官方模板：`references/forms/信息工程系新生助导申请表.docx`

## 五、学生组织与部门全景（想进学生会的看这里）

### 组织架构（校级）

- **院团委**（指导老师带队）+ **院学生会**：并称"两委会"口子里的两大校级组织
- 系里对应的是**系团总支 + 系学生会**（即"系两委会"），大一新生实际主要进系级
- **纳新节奏**：每年 **9 月中旬**系两委会部门介绍大会 + 次日面试（信工系 2025 年为 9 月 15 日介绍会/16 日面试）；院级纳新紧随其后，关注「林小团」公众号

### 系两委会特色部门（以林学系/信工系为例）

- **林学系**：团总支宣传部（公众号运营）、组织部（团日/推优入党）、志愿部（森林文化进校园、雷锋月）、办公室（**经费报销**）、记者站（晚会拍摄）、**党建服务中心**（党务、积极分子管理）
- **信工系**：组织部、新媒体中心（官方账号运营）、社团部、学习部等
- 各部门招新 QQ 群开学季在「林小团」和系公众号发布，直接加群报名

### 面试常见问题（信工系 2025 实录）

- 如何平衡学习与学生工作？
- 活动执行中遇到同学不配合怎么办？
- 现场设计一个小型新生交流活动
- 建议提前梳理高中班委/志愿经历；新媒体岗可带自己剪的视频或写的文案作品

> 学长提示：学生会经历可参与**综测加分**（部门职务分值表见 `social_practice.md`），但别贪多——学业优先，一个部门做精比三个部门挂名强。
