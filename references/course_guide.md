# 林职院选课攻略 — 正方教务系统实战指南

> 基于校内真实选课经验 + **2025 级《体育与健康3》学生选课操作手册（官方）**整理。教务系统为**正方教务系统 V9.0**。时间安排以教务处每学期通知为准。

## 一、系统入口与登录（官方手册确认）

- **地址**：https://zfjw.fjlzy.com/jwglxt（正方教务系统 V9.0，电脑浏览器打开）
- **账号**：学号（如 2025xxxxxxx 开头按入学年份）
- **密码**：**身份证后六位**（官方手册明确）
- **重要**：登录后系统**强制要求修改密码**，修改后需**重新登录**再选课——第一次进系统务必提前改，别拖到选课当天
- **登录环境**：校内网络或校外均可（高峰期可能卡顿）
- 建议使用 Chrome / Edge 浏览器

## 二、选课时间线（关键！）

- **选课高峰**：每学期期末集中选课（通常在学期最后一周到假期开始）
- **时间窗口（官方确认）**：如 2026-2027 学年第一学期选课窗口为 **2026 年 6 月 29 日 12:00 - 7 月 1 日 0:00**（出自《2025级〈体育与健康3〉学生选课操作手册》，具体以教务处通知为准）
- **体育课**：每学期需抢选体育专项课（如乒乓球、游泳、羽毛球、篮球等）
- 选课一般分阶段：预选 / 正选 / 补退选，各阶段时间以通知为准

## 二·五、官方选课操作流程（7 步）

1. 电脑浏览器打开 https://zfjw.fjlzy.com/jwglxt
2. 输入账号（学号）+ 密码（身份证后六位）登录；首次登录强制修改密码后重新登录
3. 进入「**自主选课**」，直接点击「**查询**」
4. 点击课程右侧「**选课**」按钮，选择具体项目（如 体育与健康-乒乓球/游泳/羽毛球/篮球）
5. 出现**红色「选课成功」按钮**即选课成功
6. 点击右侧**黄色条**可查看具体选课信息；如需重新选课，点击「取消」即可再选
7. 如无法登录账号，**联系辅导员**

## 三、选课前准备（提前 1-3 天）

1. **提前登录一次系统**：确认账号密码能登录、能看到选课界面（避免选课当天才发现密码错误）
2. **查好课程清单**：提前在系统里查看可选课程、上课时间、教师名单，锁定目标课程
3. **列优先级清单**：
   - 第一志愿：最想上的课（如游泳/乒乓球）
   - 第二志愿：备选（如羽毛球/篮球）
   - 保底志愿：冷门时段/冷门老师
4. **确认学分要求**：本学期应修总学分、体育课学分、必修/选修构成
5. **准备网络**：校园网或稳定宽带；选课高峰手速网速都重要

## 四、选课当天操作（高峰期实战）

### 时间策略

- **开抢前 10 分钟**：登录系统，保持在选课页面待命
- **整点开抢**：准点刷新提交，**前 1-2 分钟是黄金时间**，热门课（游泳、乒乓球）通常几十秒内满员
- **不要刷新过度**：高峰期系统卡顿是常态，页面转圈超过 15 秒再轻量刷新

### 抢课技巧

1. **开多个浏览器标签页**：不同课程各占一个标签，切换提交
2. **优先抢"人课合一"**：体育课优先选自己感兴趣的、好过课的；游泳(康邦优先)、乒乓球是热门
3. **提交失败立即换备选**：第一志愿满员不要恋战，马上提交第二志愿
4. **利用补退选**：正选没抢到别慌，补退选阶段常有人退课，每天刷几次
5. **错峰**：如果系统支持分时段选课（按年级/系部分批），按自己批次的时间进

### 常见课程（体育专项，参考）

- 体育与健康-乒乓球
- 体育与健康-游泳
- 体育与健康-羽毛球
- 体育与健康-篮球

> 课程名以系统实际显示为准（通常带「体育与健康-」前缀）。教师以系统当期名单为准。

## 五、选课避坑清单

| 坑 | 说明 |
|----|------|
| 密码没提前改 | 选课当天改密码可能被要求重新登录，耽误时间 |
| 只看课名不看时段 | 有些课上课时间与必修冲突，选课前先对照课表 |
| 目标课全扎堆 | 所有志愿都填热门课，满了就只能捡漏 |
| 忽略补退选 | 正选失败就放弃，其实补退选是第二次机会 |
| 用手机选课 | 高峰期手机端容易卡，优先电脑 + 有线/稳定网络 |
| 忘记确认学分 | 选完不核对学分，学期末发现学分不够 |

## 六、课程免修与学分置换（官方细则：闽林院教〔2020〕26号）

> 满足条件可申请免修，不参加除两课（思政课）、形势政策及实践教学环节外的课程学习而直接获得成绩与学分。

### 谁可以申请（常见情形）

| 情形 | 免修内容 |
|------|----------|
| 通过英语 B 级或以上 | 《大学英语》类（A级4分/B级5分/CET4 6分/CET6 8分） |
| 通过全国计算机等级考试（非计算机专业） | 《计算机基础与操作》（最多认定 4 学分） |
| 残疾（县级医院证明） | 体育课 |
| 退役军人入学/复学 | 军事训练与军事理论 |
| 自学考试/外校同课程 60 分以上 | 相同课程（获得相应学分） |
| 创新创业/社会实践/发表论文/专利 | 专利：发明12/实用新型8/外观设计6学分；技术改造国家级12~院级2学分 |
| 职业资格证书（学院组织培训考试） | 自选免修 1 门相关专业课；1+X 证书高级8/中级6/初级4学分，成绩按85分记载 |
| 职业技能竞赛获奖 | 国赛一等16/二等14/三等12；省赛12/10/8；市赛8/6/4；县赛6/4/2；院赛4/2/1 学分（同类不累计，按最高级别） |
| 智慧树/超星网课合格 | 免修相同学分相关课程 |

### 审批程序（重要时间点）

1. **开学初两周内**办理（教务处发通知），过时不候
2. 到**系办公室领取《课程免修与学分置换申请表》**（一式三份）
3. 附成绩证明/证书/病历等原件 + 复印件（教务处存档）
4. 任课教师成绩认定意见 → **教务处审批** → 三份分别存教务处、教学系、学生
5. 免修**分学期申请**；应附证书/成绩证明复印件

### 申请对象完整版见细则（13 条）

- 官方申请表模板：`references/forms/课程免修与学分置换申请表.docx`（用户要填表时直接交付该文件）

## 七、选课后

- **核对课表**：选课完成后在系统导出/截图课表（我的课表），确认无冲突、无遗漏
- **关注通知**：开学初关注教务处补退选、教材领取通知
- **退课规则**：补退选阶段可退可选，逾期不可退，务必在期限内处理

## 八、转专业（学籍管理规定 + 转专业实施细则）

### 可以申请转专业的情形（满足其一）

1. **第一学期各门课程考试成绩均为及格及以上**（最常见路径：大一上好好考！）
2. 确有专长、有相关成果，转专业更能发挥专长
3. 因患疾病或特殊困难，经学院指定**二级甲等以上医院**证明不宜在原专业学习
4. 原专业停招（学院调整学科专业建设）
5. 休学创业 / 退役复学学生优先考虑（退役士兵可在同科类范围内优先选专业）
6. 其他经学院审核确认的特殊情况

### 不允许转专业的情形（红线）

- **五年一贯制、三二分段制、单独招生（春招高职分类）、中职推免、艺术类、注册入学、专升本**等特殊类型录取的学生**不得转专业**
- 高职招考**中职生源**学生不允许转专业（高中生源只能在高中生源类别内转）
- 第一学期有**一门及以上课程不合格**者
- 入学时已转过/重新选择过专业、二次以上转专业
- 应作退学或受开除学籍处分者；保留入学资格/休学期间
- 学制长的专业不能转学制短的专业
- 通过降分录取的只能在允许降分录取的专业中互转

### 申请时间与流程（每年只有一次机会！）

1. **第一学期结束前一周**内向所在系提出申请（其余时间不受理）
2. 填写《福建林业职业技术学院学生转专业申请表》→ 转出系主任签字 → 转入系主任签字 → 交教务处教材与学籍管理科
3. 第二学期开学由教务处统一审核 → **院长办公会**研究通过 → 公示 **5 天** → 报省教育厅批准
4. 批准后由各系负责安排转专业学生的学习生活
- 原则上转出/转入人数不超过本专业当年招生数的 **3%-5%**；在校期间**只允许申请转一次**；转专业后须按新专业培养方案修完全部课程才能毕业

## 九、毕业与结业条件（学生管理规定）

- **最长修业年限**：三年制高职 **6 年**、五年制高职 **8 年**（含休学和保留学籍）；当兵入伍保留学籍至退伍后 2 年，不计入
- **毕业三条件**：
  1. 修完人才培养方案规定的全部内容（含理论、实训、实习、毕业设计、军训、劳动等）并考核合格
  2. **在校期间所受处分已解除** + 综合素质考评合格
  3. 体测达标（大学生体质健康测试合格）+ 满足本专业培养方案其他条件
- **课程不及格**：正常补考 1 次 → 不合格申请重修 → 重修考试不合格再补考 1 次 → 仍不合格可在学制内继续重修
- **结业换毕业**：毕业审核时 1-3 门不合格准予结业（发结业证书）；离校后**一年内**可申请重修，全部合格换发毕业证
- 学分参考：三年制约 **125-135 学分**（理论课 16 学时/学分，实习实训 30 学时/周计 1 学分）

## 十、专升本攻略（高职学生的黄金跳板）

### 基本情况

- 福建专升本按**类别**报考（农林类、理工1类、建筑类、新闻类等），考上后插入本科大三再读 2 年
- 林职院学子战绩：信工系云计算专业**林国程以理工1类全省第 2 名录取厦门理工学院**（官网「榜样的力量」系列）
- **公共课是拉分关键**：大学英语、高等数学（理工类）或大学语文；农林类学生优先报**农林类**（专业契合度高、专业课占优势）

### 学长备考经验（官网榜样专访：林国程·全省第2）

| 科目 | 攻略 |
|------|------|
| 思政理论 | 不要直接开背，先理解基础概念再背（磨刀不误砍柴工） |
| 高等数学 | **大一就要提前学**，利用学校高数课程打好基础，掌握题型做题步骤 |
| 大学英语 | 靠长期积累，**单词是重中之重**，每天定量背；时间充裕先考四级 |
| 信息技术基础 | **分值占比大、拿分容易、性价比最高**，多找材料多做习题 |

- 心态：按部就班执行每日计划、注意劳逸结合；确立目标
- 校内资源：教务处/继续教育中心发布政策通知、组织备考讲座；多问辅导员和上岸的学长学姐
- **避坑**：一切以**福建省教育考试院**官方信息为准，警惕"内部消息""包过"广告

## 十一、高频问题

**Q：选课系统进不去/一直转圈？**
A：高峰期服务器压力大，正常现象。开 2-3 个标签页轮着试，间隔刷新，别连续猛刷。

**Q：体育课没抢到心仪的怎么办？**
A：①补退选阶段蹲退课；②下学期再选（体育课每学期都有）；③问体育老师是否有调剂名额。

**Q：课表怎么导出？**
A：正方教务系统「培养方案/我的课表」页面一般支持导出/打印，也可截图保存。

**Q：学分怎么算？**
A：各专业培养方案不同，按本专业教学计划要求，选课页会显示已选学分，对照培养方案补缺。
