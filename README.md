# 福建林业职业技术学院—校园百事通 Skill

> 把母校的一切装进 Skill：学校概况、双校区新生入学指南、选课抢课攻略、校园探索打卡与出片机位、周边景点周末游、防诈骗指南、外卖省钱攻略、考研就业全周期导航、林职冷知识库。
> 宝藏母校 Skill 大赛参赛作品 · WorkBuddy Skill

一个专为 **福建林业职业技术学院（林职院）** 打造的 AI Skill。像一位在校园里生活多年的资深学长/学姐，热情、具体、接地气地回答新生和在校生关于学校的一切问题——从怎么报到、宿舍咋样、食堂吃啥，到怎么抢课、转专业、评奖学金、防诈骗、点外卖省钱、规划升学就业。

## 🚀 安装使用

**WorkBuddy 用户：**

1. 克隆或下载本仓库；
2. 将整个 `fjlzy-campus-baishitong/` 文件夹复制到 `~/.workbuddy/skills/` 目录下；
3. 在 WorkBuddy 对话中直接提问，例如：
   - 「林职院宿舍怎么样？」
   - 「新生报到流程是什么？」
   - 「怎么在正方教务系统抢课？」

**通用**：任何支持 SKILL.md 规范的 AI 助手平台均可加载本 Skill（纯数据 + 文本输出，无第三方依赖）。

## 🕷️ 老师评价检索脚本

`scripts/teacher_review_crawler.py` 采用**按需运行**设计：

- **双触发条件**：用户明确提到具体老师姓名 + 明确表达想了解评价时才运行；
- **六引擎链式检索**：移动搜狗 → 神马 → 桌面搜狗 → DuckDuckGo → 百度 → Bing，任一通道被反爬自动跳下一个；
- **隐私红线**：手机号/身份证/QQ 自动正则打码；检索结果**只生成一次性报告，不落库**；
- **不碰登录态**：不使用任何 Cookie/登录凭据，只采集公开可见内容；小红书/抖音评论区内容需用户自行在 App 内查看，脚本只负责找到并递上笔记链接。

```bash
# 发现模式：先列出校内有口碑线索的老师让用户选择
python scripts/teacher_review_crawler.py --discover "宝藏老师"

# 深挖模式：查某位具体老师的公开评价
python scripts/teacher_review_crawler.py 罗春玉 --dept 旅游管理
```
